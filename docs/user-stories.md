# User Stories

- **US-001** As an existing user, I want to log in and restore my session after a page refresh so that I can access authorized functions. Traces to FR-001, FR-002, and FR-003.
- **US-002** As HR, I want to create, search, view, update, filter, and safely delete jobs so that recruitment positions remain current. Traces to FR-004 and FR-005.
- **US-003** As a MANAGER, I want to view jobs without changing them so that I can review active recruitment needs. Traces to FR-003 and FR-004.
- **US-004** As HR, I want to manage candidate information and search or filter candidates so that candidate data is easy to find. Traces to FR-006 and FR-007.
- **US-005** As HR, I want to upload a CV and retain extracted PDF or DOCX text so that later AI functions can use approved candidate data. Traces to FR-008.
- **US-006** As a MANAGER, I want read-only Candidate access so that I can review candidate information without altering HR records. Traces to FR-003 and FR-006.
- **US-007** As HR, I want to connect a candidate to a job and update the recruitment status so that the application process is recorded. Traces to FR-009 and FR-010.
- **US-008** As HR, I want to schedule and maintain interviews so that candidates and interviewers have an organized plan. Traces to FR-011.
- **US-009** As an authorized evaluator, I want to record three scores and a comment so that a human assessment is retained. Traces to FR-012.
- **US-010** As HR, I want AI to summarize CV information and suggest interview questions so that I can prepare efficiently without delegating the hiring decision. Traces to FR-013, FR-014, and BR-006.
- **US-011** As HR, I want an AI-generated email draft so that I can review and copy a response without automatic sending. Traces to FR-015 and BR-006.
- **US-012** As an authenticated user, I want a concise dashboard so that I can see core recruitment counts. Traces to FR-017.
- **US-013** As the student, I want a health endpoint and verifiable test evidence so that database connectivity and implemented behavior can be demonstrated. Traces to FR-018 and NFR-010.
