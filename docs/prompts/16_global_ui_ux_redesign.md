## CTA principle
ONE obvious primary CTA per page.

Examples:
- Jobs: `+ Thêm vị trí tuyển dụng`
- Candidates: `+ Thêm ứng viên`
- Applications: `+ Tạo hồ sơ ứng tuyển`
- Interviews: `+ Lên lịch phỏng vấn`
- Evaluation: `Lưu đánh giá`

Primary CTA: blue background, white text.  
Secondary: white, gray border.  
Danger: red only for destructive actions.
