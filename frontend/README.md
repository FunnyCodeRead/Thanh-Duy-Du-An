# React Frontend

Frontend chính của AI Recruitment Management System cho phạm vi M1/M2.

```powershell
npm install
npm run dev -- --host 127.0.0.1
```

Vite chạy tại `http://127.0.0.1:5173` và proxy `/api`, `/uploads` sang Flask tại `http://127.0.0.1:5000`.

Kiểm tra trước khi bàn giao:

```powershell
npm run lint
npm run build
```

Xem hướng dẫn đầy đủ tại `../README.md`.
