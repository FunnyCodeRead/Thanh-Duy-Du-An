# Code Review

Read approved requirements, architecture, implementation, and tests. Review correctness, traceability, duplication, error handling, parameterized SQL, frontend API use, role enforcement, upload behavior, and coverage.

Classify actionable findings as `CRITICAL`, `HIGH`, `MEDIUM`, or `LOW`, cite the affected file and evidence, and record them in `docs/code-review.md`.

Do not modify code during the review. Distinguish verified defects from recommendations and do not claim a clean review without inspecting and testing the current state.
